# UI Admin Helper

> **Отдельно от Admin JSON Toolkit.** JSON Search / Base Price / Competitors — в [`../admin-json-toolkit/`](../admin-json-toolkit/).  
> UI Admin остаётся своим userscript: кнопка слева снизу, токены темы C ([`../shared/ui-kit/TOKENS.md`](../shared/ui-kit/TOKENS.md)).


Утилита для управления отображением блоков в Django Admin панели HotelLab.

## 📋 Описание

**UI Admin Helper** - это скрипт для Tampermonkey, который расширяет функциональность Django Admin панели HotelLab. Скрипт добавляет удобные инструменты для управления отображением различных блоков: скрытие архивных сезонов, категорий номеров, пользователей и сворачивание JSON редакторов.

## ✨ Возможности

### Управление отображением блоков
- 📦 **Архивные сезоны** - скрытие/показ блоков сезонов с установленным checkbox "Is archived"
- 🏨 **Категории номеров** - скрытие/показ блока с категориями номеров
- 👥 **Пользователи** - скрытие/показ блока с пользователями отеля
- 📝 **Сворачивание JSON редакторов** - возможность сворачивать/разворачивать блоки конфигураций

### Интерфейс
- ⚙️ **Кнопка настроек** - фиксированная кнопка в левом нижнем углу страницы
- 🎛️ **Popup настроек** - удобное меню для управления всеми опциями
- 👁️ **Иконки состояния** - визуальная индикация (открытый/закрытый глаз)

### Автоматическое сохранение
- 💾 **Сохранение состояния** - все настройки сохраняются между страницами и сессиями
- 🔄 **Восстановление** - при загрузке страницы применяются сохраненные настройки

## 🚀 Установка

### Шаг 1: Установка Tampermonkey

1. Установите расширение [Tampermonkey](https://www.tampermonkey.net/)
2. Откройте Tampermonkey Dashboard

### Шаг 2: Установка скрипта

1. Откройте файл `ui-admin.user.js`
2. Скопируйте весь код
3. В Tampermonkey Dashboard создайте новый скрипт
4. Вставьте код и сохраните (Ctrl+S)

### Шаг 3: Активация

1. Перейдите на страницу редактирования отеля: `https://app.hotellab.io/ru/AdminOnly/mainApp/hotels/*`
2. В левом нижнем углу должна появиться кнопка настроек ⚙️
3. Нажмите на кнопку для открытия меню настроек

## 🔧 Как работает

### Архивные сезоны

Скрипт автоматически находит все блоки с классом `.inline-related.dynamic-hotelSeasonsConfigs` и проверяет checkbox `is_archived`. Если checkbox установлен, блок скрывается (по умолчанию).

**Как использовать:**
1. Откройте popup настроек (кнопка ⚙️)
2. Переключите "Архивные сезоны"
3. При включении - все архивные сезоны будут видны
4. При выключении - архивные сезоны будут скрыты

### Категории номеров

Скрипт скрывает/показывает блок с ID `hotelRoomsTypesTrnsit-group`, который содержит таблицу с категориями номеров.

**Как использовать:**
1. Откройте popup настроек
2. Переключите "Категории номеров"
3. Блок будет скрыт или показан в зависимости от состояния

### Пользователи

Скрипт скрывает/показывает блок с ID `Hotels_owner-group`, который содержит информацию о пользователях отеля.

**Как использовать:**
1. Откройте popup настроек
2. Переключите "Пользователи"
3. Блок будет скрыт или показан в зависимости от состояния

### Сворачивание JSON редакторов

Скрипт добавляет кнопку сворачивания рядом с label каждого JSON редактора. Поддерживаются следующие блоки:

- `id_emailmessage` - Текст в E-mail
- `id_pms_interface_reservations_config` - PMS Interface Reservations Config
- `id_pms_interface_config` - PMS Interface Config
- `id_report_config` - Report Config
- `id_custom_calendar_config` - Custom Calendar Config
- `id_extension` - Extension
- `id_travel_db_token` - Travel DB Token
- `id_pms_config` - PMS Config
- `id_blocks_config` - Blocks Config
- `id_statistics_config` - Statistics Config

**Как использовать:**
1. Найдите нужный блок конфигурации на странице
2. Рядом с label вы увидите кнопку со стрелкой ⬇️
3. Нажмите на кнопку для сворачивания/разворачивания блока
4. Состояние сохраняется автоматически

## 📊 Сохранение настроек

Все настройки сохраняются в хранилище Tampermonkey через `GM_setValue` и доступны на всех страницах:

- **Архивные сезоны**: `ui_admin_show_archived`
- **Категории номеров**: `ui_admin_show_room_categories`
- **Пользователи**: `ui_admin_show_users`
- **JSON редакторы**: отдельный ключ для каждого блока

При следующем посещении страницы все настройки будут применены автоматически.

## ⚙️ Технические детали

### Отслеживание изменений

Скрипт использует `MutationObserver` для отслеживания:
- Добавления новых элементов на странице
- Изменений checkbox'ов (особенно `is_archived`)
- Динамической загрузки JSON редакторов

### Инициализация

Скрипт инициализируется при:
- Загрузке страницы (`document-idle`)
- Добавлении новых элементов в DOM
- Изменении состояния checkbox'ов

### Производительность

- Минимальное влияние на производительность
- Оптимизированные селекторы
- Кэширование найденных элементов
- Ограничение количества попыток инициализации

## 🐛 Устранение проблем

### Кнопка настроек не появляется

1. Убедитесь, что вы на странице `app.hotellab.io/ru/AdminOnly/mainApp/hotels/*`
2. Проверьте, что скрипт активен в Tampermonkey Dashboard
3. Обновите страницу (F5)
4. Откройте консоль браузера (F12) для проверки ошибок

### Настройки не сохраняются

1. Убедитесь, что Tampermonkey имеет разрешение `GM_setValue` и `GM_getValue`
2. Проверьте настройки Tampermonkey → Settings → Storage

### JSON редакторы не сворачиваются

1. Убедитесь, что JSON редактор загрузился полностью
2. Подождите несколько секунд - скрипт пытается инициализироваться несколько раз
3. Обновите страницу
