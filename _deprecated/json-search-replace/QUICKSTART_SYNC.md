# ⚡ Быстрый старт - Синхронизация данных

## 💖 Синхронизация Intercept

### Что делает
Копирует все intercept данные из основного конфига во все сезонные конфиги.

### Как использовать
1. Откройте модальное окно поиска
2. Нажмите **"💖 Перезаписать intercept"**
3. Готово! ✅

### Время выполнения
~5 секунд для всех конфигов

---

## 🔧 Синхронизация Parsing

### Что делает
Синхронизирует список отелей-конкурентов с выбранными полями.

### Быстрый старт
1. Откройте модальное окно поиска
2. Нажмите **"🔧 Перезаписать Parsing"**
3. Выберите нужные поля (или оставьте по умолчанию)
4. Нажмите **"Синхронизировать"**
5. Готово! ✅

### Время выполнения
~3-10 секунд в зависимости от количества конфигов

---

## 📝 Обязательные поля Parsing

Эти поля синхронизируются **всегда** (без выбора):
- `standart_category` - категории номеров
- `hotel_title` - название отеля

## 📋 Дополнительные поля Parsing

Выберите только те, которые нужно синхронизировать:
- `concurents_influence` - влияние конкурента
- `take_max_price` - брать максимальную цену
- `force_rate` - принудительный тариф
- `force_key` - принудительный ключ
- `new_id` - новый идентификатор
- `genius` - настройки Genius
- `tax` - налоги
- `tax_per_person` - налог на человека
- `stay_length` - длительность проживания
- `price_source` - источник цены
- `clip` - обрезка значений

## ⚠️ Что нужно знать

### Синхронизация Intercept
- ✅ Автоматическая (не требует выбора полей)
- ✅ Сохраняет месячные данные каждого сезона
- ✅ Быстрая (5 секунд)

### Синхронизация Parsing
- ✅ Гибкая (выбор полей)
- ✅ Сохраняет порядок из основного конфига
- ✅ Сохраняет `selfID` каждого конфига
- ✅ Валидирует JSON после изменений
- ⚠️ НЕ изменяет не выбранные поля

## 🐛 Просмотр логов

Для проверки результата:
1. Нажмите **F12** (консоль браузера)
2. Перейдите на вкладку **"Console"**
3. Просмотрите логи синхронизации

### Что искать в логах:
- ✅ Зеленые сообщения = успех
- 🔴 Красные сообщения = ошибка
- 🔄 Синие сообщения = процесс

## 💡 Полезные советы

1. **Первый раз?** Включите debug режим (чекбокс внизу справа)
2. **Не уверены?** Синхронизируйте по одному полю за раз
3. **Большие изменения?** Проверьте основной конфиг перед синхронизацией
4. **Что-то пошло не так?** Проверьте логи в консоли (F12)
