# 📥 Инструкция по установке

## Быстрая установка (5 минут)

### 1️⃣ Установка Tampermonkey

1. **Откройте Chrome Web Store**
   - Перейдите по ссылке: [Tampermonkey](https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo)
   - Нажмите **"Добавить в Chrome"**
   - Подтвердите установку

2. **Проверьте установку**
   - В правом верхнем углу браузера должна появиться иконка Tampermonkey 🐒
   - Нажмите на неё - должно открыться меню

### 2️⃣ Установка скрипта

1. **Скачайте файл скрипта**
   - Откройте файл `json-search.user.js` в этом репозитории
   - Нажмите ["Raw"](https://git.b4dcat.ru/b4dcat/json-search-replace/raw/branch/main/json-search.user.txt)
   - Скопируйте весь код (Ctrl+A, Ctrl+C)

2. **Создайте новый скрипт в Tampermonkey**
   - Нажмите на иконку Tampermonkey 🐒
   - Выберите **"Dashboard"**
   - Нажмите **"+"** (плюс) для создания нового скрипта

3. **Вставьте код**
   - Удалите весь существующий код в редакторе
   - Вставьте скопированный код (Ctrl+V)
   - Нажмите **Ctrl+S** для сохранения

### 3️⃣ Активация

1. **Убедитесь, что скрипт включен**
   - В Dashboard Tampermonkey скрипт должен быть **включен** (зеленая галочка)
   - Если выключен - нажмите на переключатель

2. **Перейдите на страницу HotelLab**
   - Откройте: `https://app.hotellab.io/ru/AdminOnly/mainApp/hotels/*`
   - Дождитесь полной загрузки страницы
   - В правом верхнем углу должна появиться кнопка **"🔍 JSON Search & Replace"**

## ✅ Проверка установки

### Что должно появиться:

1. **Иконка Tampermonkey** в браузере
2. **Кнопка "🔍 JSON Search & Replace"** на странице HotelLab
3. **Debug чекбокс** (появляется при открытии модального окна)

### Если что-то не работает:

1. **Обновите страницу** (F5)
2. **Проверьте консоль браузера** (F12 → Console)
3. **Убедитесь, что вы на правильной странице** HotelLab
4. **Перезапустите браузер**

## 🔧 Дополнительные настройки

### Настройки Tampermonkey

1. **Откройте Dashboard** Tampermonkey
2. **Нажмите на шестеренку** (Settings)
3. **Рекомендуемые настройки**:
   - ✅ **Check for updates**: Every day
   - ✅ **Show update notification**: Yes
   - ✅ **Allow access to file URLs**: Yes (если нужно)

### Настройки браузера

1. **Разрешите выполнение скриптов**:
   - Chrome: Настройки → Конфиденциальность → Настройки сайтов → JavaScript → Разрешить
   - Firefox: about:config → javascript.enabled = true

## 🚨 Устранение проблем

### Проблема: Кнопка не появляется
**Решение:**
1. Проверьте URL - должен содержать `hotellab.io`
2. Обновите страницу
3. Проверьте консоль на ошибки

### Проблема: Скрипт не загружается
**Решение:**
1. Убедитесь, что Tampermonkey включен
2. Проверьте, что скрипт активен в Dashboard
3. Перезапустите браузер

### Проблема: Ошибки в консоли
**Решение:**
1. Включите debug режим в скрипте
2. Скопируйте ошибку и сообщите разработчику
3. Попробуйте переустановить скрипт

## 📞 Поддержка

Если у вас возникли проблемы с установкой:

1. **Проверьте версию браузера** - нужен Chrome 80+ или Firefox 75+
2. **Проверьте версию Tampermonkey** - нужна версия 4.0+
3. **Попробуйте в режиме инкогнито** - отключите другие расширения
