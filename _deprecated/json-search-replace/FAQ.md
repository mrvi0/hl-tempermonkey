# ❓ Часто задаваемые вопросы

## 🚀 Установка и настройка

### Q: Скрипт не загружается на странице
**A:** Проверьте следующее:
1. Убедитесь, что Tampermonkey установлен и включен
2. Проверьте, что вы находитесь на странице HotelLab
3. Обновите страницу (F5)
4. Проверьте консоль браузера на ошибки (F12)

### Q: Кнопка "🔍 JSON Search & Replace" не появляется
**A:** Возможные причины:
1. Страница еще не загрузилась полностью - подождите
2. Вы не на правильной странице HotelLab
3. Скрипт отключен в Tampermonkey Dashboard
4. Ошибка в коде - проверьте консоль

### Q: Как обновить скрипт до новой версии?
**A:** 
1. Скачайте новую версию `json-search.user.js`
2. Откройте Tampermonkey Dashboard
3. Найдите скрипт и нажмите "Редактировать"
4. Замените весь код новым
5. Сохраните (Ctrl+S)

## 🔍 Поиск и замена

### Q: Поиск не находит результаты
**A:** Проверьте:
1. Правильность введенного текста
2. Попробуйте отключить "Учитывать регистр"
3. Убедитесь, что JSON редакторы загружены на странице
4. Попробуйте использовать блочный поиск

### Q: Замена не работает
**A:** Возможные причины:
1. Не введен текст для замены
2. JSON содержит синтаксические ошибки
3. Включите debug режим и проверьте консоль
4. Попробуйте заменить в конкретном конфиге

### Q: Как использовать регулярные выражения?
**A:** 
1. Включите чекбокс "Регулярные выражения"
2. Введите regex паттерн в поле поиска
3. Примеры:
   - `[0-9]+` - найти все числа
   - `".*"` - найти все строки в кавычках
   - `https?://[^\s]+` - найти все URL

### Q: Что такое блочный поиск?
**A:** Блочный поиск игнорирует:
- Пробелы и табуляции
- Переносы строк
- Форматирование JSON

Полезен для поиска многострочных блоков текста.

## 🎯 Интерфейс

### Q: Как переключаться между конфигами?
**A:** Используйте стрелки пагинации внизу модального окна:
- **←** - предыдущий конфиг
- **→** - следующий конфиг
- **Номер страницы** - показывает текущий конфиг

### Q: Что показывает diff preview?
**A:** Diff preview показывает:
- 🔴 **Красный** - что будет удалено (старый текст)
- 🟢 **Зеленый** - что будет добавлено (новый текст)
- **Контекст** - окружающий текст для понимания

### Q: Как включить debug режим?
**A:** 
1. Откройте модальное окно поиска
2. Нажмите на чекбокс "Debug" в правом нижнем углу
3. Откройте консоль браузера (F12)
4. Просматривайте подробные логи

## 🐛 Проблемы и ошибки

### Q: Ошибка "JSON.parse: unexpected token"
**A:** Это означает, что JSON содержит синтаксические ошибки:
1. Проверьте валидность JSON в конфиге
2. Используйте debug режим для диагностики
3. Попробуйте заменить в конкретном конфиге

### Q: Скрипт работает медленно
**A:** Для улучшения производительности:
1. Используйте точные поиски вместо общих
2. Избегайте слишком сложных регулярных выражений
3. Проверьте количество конфигов на странице
4. Закройте ненужные вкладки браузера

### Q: Замена в конкретном конфиге влияет на другие
**A:** Это баг, который исправлен в версии 2.0.0:
1. Обновите скрипт до последней версии
2. Если проблема остается, включите debug режим
3. Сообщите об ошибке с логами из консоли

## 🔧 Технические вопросы

### Q: Какие браузеры поддерживаются?
**A:** Скрипт работает в:
- Chrome 80+
- Firefox 75+
- Edge 80+
- Safari 13+

### Q: Какой версии Tampermonkey нужна?
**A:** Минимальная версия Tampermonkey 4.0.0

### Q: Безопасно ли использовать скрипт?
**A:** Да, скрипт:
- Работает только на страницах HotelLab
- Не отправляет данные на внешние серверы
- Не сохраняет информацию локально
- Имеет открытый исходный код

### Q: Можно ли модифицировать скрипт?
**A:** Да, скрипт распространяется под лицензией MIT:
- Можно изменять код
- Можно распространять
- Можно использовать в коммерческих целях
- Нужно сохранить уведомление об авторских правах
