# 💰 Base Price Maker

## Описание

**Base Price Maker** — это инструмент для автоматической генерации `base_price` из `min_price` или `max_price` в JSON-редакторах на странице HotelLab.

### Основные возможности:

* ✅ Автоматический поиск всех JSON-редакторов на странице
* ✅ Генерация `base_price` из `min_price` или `max_price`
* ✅ Два режима расчета: процент или абсолютное значение
* ✅ Поддержка знаков `+` и `-` для добавления/вычитания
* ✅ Автоматическое размещение `base_price` сразу после источника данных
* ✅ Поддержка различных форматов данных (числа, массивы, объекты)

## 🚀 Быстрый старт

### 1. Откройте Base Price Maker

1. Перейдите на страницу HotelLab с JSON-редакторами
2. В **левом нижнем углу** страницы найдите кнопку **"BP"**
3. Нажмите на кнопку — откроется popup с настройками

### 2. Настройте параметры

1. **Выберите источник данных:**
   * `min_price` — использовать минимальные цены
   * `max_price` — использовать максимальные цены

2. **Выберите режим расчета:**
   * **Процент (%)** — расчет процента от исходного значения
   * **Значение** — абсолютное значение (сложение/вычитание)

3. **Введите значение:**
   * Для режима **Процент**: `100` (100%), `+20` (добавить 20%), `-10` (вычесть 10%)
   * Для режима **Значение**: `10` (прибавить 10), `+50` (прибавить 50), `-30` (вычесть 30)

### 3. Обработайте редакторы

1. Нажмите **"Найти редакторы"** — скрипт найдет все JSON-редакторы на странице
2. Проверьте список найденных редакторов
3. Нажмите **"Обработать"** — скрипт создаст/обновит `base_price` во всех найденных редакторах

## 📖 Подробное описание

### Режимы расчета

#### Режим "Процент (%)"

Рассчитывает процент от исходного значения:

* **`100`** — 100% от значения (равно исходному)
* **`+20`** — добавить 20% (умножить на 1.20)
* **`-10`** — вычесть 10% (умножить на 0.90)
* **`50`** — 50% от значения (умножить на 0.50)

**Примеры:**
```
min_price: 304, значение: +20%
→ base_price: 365 (304 × 1.20)

min_price: 304, значение: -10%
→ base_price: 274 (304 × 0.90)

min_price: 304, значение: 50%
→ base_price: 152 (304 × 0.50)
```

#### Режим "Значение"

Добавляет или вычитает абсолютное значение:

* **`10`** — прибавить 10
* **`+50`** — прибавить 50
* **`-30`** — вычесть 30

**Примеры:**
```
min_price: 304, значение: +20
→ base_price: 324 (304 + 20)

min_price: 304, значение: -30
→ base_price: 274 (304 - 30)
```

### Форматы данных

Скрипт поддерживает различные форматы `min_price`/`max_price`:

#### 1. Простое число
```json
{
  "min_price": 304,
  "base_price": 365  // ← создается автоматически
}
```

#### 2. Объект с массивами
```json
{
  "min_price": {
    "1": [304],
    "2": [280]
  },
  "base_price": {
    "1": [365],  // ← создается автоматически
    "2": [336]
  }
}
```

#### 3. Объект с числами (не массивы)
```json
{
  "min_price": {
    "1": 304,
    "2": 280
  },
  "base_price": {
    "1": 365,  // ← создается автоматически (не массив!)
    "2": 336
  }
}
```

### Автоматическое размещение

`base_price` автоматически размещается **сразу после** выбранного источника данных:

**До обработки:**
```json
{
  "profile_name": "default",
  "min_price": {"1": [304]},
  "max_price": {"1": [400]},
  "other_field": "value"
}
```

**После обработки (если выбран min_price):**
```json
{
  "profile_name": "default",
  "min_price": {"1": [304]},
  "base_price": {"1": [365]},  // ← сразу после min_price
  "max_price": {"1": [400]},
  "other_field": "value"
}
```

## 💾 Сохранение настроек

Все настройки автоматически сохраняются в localStorage браузера:

* Выбранный источник данных (`min_price`/`max_price`)
* Режим расчета (Процент/Значение)
* Введенное значение

При следующем открытии popup все настройки будут восстановлены.

## ❓ FAQ по Base Price Maker

### Q: Почему не все редакторы обрабатываются?

**A:** Проверьте:

1. Убедитесь, что в редакторах есть `min_price` или `max_price`
2. Проверьте, что данные в правильном формате (число, массив или объект)
3. Включите debug режим и посмотрите логи в консоли

### Q: Как обработать только один редактор?

**A:** В текущей версии обрабатываются все найденные редакторы. Для обработки одного редактора:

1. Временно скройте другие редакторы на странице
2. Или используйте функцию поиска и замены для ручной обработки

### Q: Можно ли отменить изменения?

**A:** Да, используйте стандартную функцию отмены браузера (Ctrl+Z) или восстановите данные из резервной копии.

### Q: Что делать, если base_price уже существует?

**A:** Скрипт автоматически **перезаписывает** существующий `base_price` новыми значениями.

### Q: Поддерживаются ли отрицательные значения?

**A:** Да, можно использовать отрицательные значения в режиме "Значение":

* `-10` — вычесть 10
* `-50` — вычесть 50

### Q: Как работает обработка пустых массивов?

**A:** Пустые массивы сохраняются как пустые массивы:

```json
{
  "min_price": {"1": []},
  "base_price": {"1": []}  // ← пустой массив сохраняется
}
```

**A:** Возможные причины:

### Q: Как использовать регулярные выражения?

**A:**

1. Включите чекбокс "Регулярные выражения"
2. Введите regex паттерн в поле поиска
3. Примеры:
   * `[0-9]+` - найти все числа
   * `".*"` - найти все строки в кавычках
   * `https?://[^\s]+` - найти все URL

**A:** Блочный поиск игнорирует:

Полезен для поиска многострочных блоков текста.

## Пример регулярных выражений

*Нужно из*
`"Best Available Rate_2": "A-RACK:SKN:1,A-RACK:SKN:2"`
*Сделать*
`"Best Available Rate_2": "A-RACK:SKN:2",`
`"Best Available Rate_1": "A-RACK:SKN:1"`

```
Поиск
"Best Available Rate_2": "A-RACK:([^:]+):1,A-RACK:([^:]+):2"

Замена
"Best Available Rate_2": "A-RACK:$2:2", "Best Available Rate_1": "A-RACK:$1:1"
```
