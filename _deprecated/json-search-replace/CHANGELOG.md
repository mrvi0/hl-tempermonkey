## [2.0.0] - 2025-09-12

### ✨ Добавлено
- **Debug режим** с переключателем в UI
- **Функция замены в конкретном конфиге** (`replaceInCurrentConfig`)
- **Функция синхронизации search results** (`updateSearchResultsForDiff`)
- **Оптимизированная система логирования** с уровнями (DEBUG/INFO/SUCCESS/ERROR)
- **Полноэкранный режим модального окна** для лучшего UX
- **Индивидуальные скроллы** для search results и diff контейнеров
- **Фиксированная пагинация** внизу модального окна
- **Стилизованный debug чекбокс** в правом нижнем углу

### 🔧 Изменено
- **Модальное окно** теперь использует flexbox для лучшего распределения пространства
- **Diff контейнер** получил максимальную высоту и собственный скролл
- **Search results** получили ограниченную высоту с индивидуальным скроллом
- **Пагинация** зафиксирована внизу и не скроллится с содержимым
- **Логирование** оптимизировано - в обычном режиме показываются только SUCCESS и ERROR
- **HTML структура** улучшена для лучшей семантики

### 🐛 Исправлено
- **Критический баг**: замена в конкретном конфиге больше не влияет на основной конфиг
- **Дублирование ID**: исправлен конфликт с кнопкой `hl-replace-current-btn`
- **Кнопка "Применить"**: теперь работает без предварительного нажатия "Поиск"
- **Синхронизация view**: search results и diff теперь синхронизированы при пагинации
- **Обновление состояния**: `currentResult.jsonString` корректно обновляется после замены
- **Z-index кнопки подтверждения**: исправлено наложение элементов

### 🎨 Улучшения UI/UX
- **Размеры модального окна**: теперь занимает почти весь экран (`calc(100vh - 80px)`)
- **Скролл контейнеров**: каждый блок имеет собственный скролл
- **Debug чекбокс**: появляется только при открытом модальном окне
- **Цветовая схема**: улучшена читаемость текста в diff view
- **Анимации**: добавлены плавные переходы для debug переключателя

### 🔄 Рефакторинг
- **Функция `log()`**: переписана с поддержкой debug режима и цветового кодирования
- **CSS структура**: оптимизирована с использованием flexbox
- **JavaScript код**: улучшена читаемость и производительность
- **Обработка событий**: оптимизирована для лучшей производительности

### 📊 Статистика изменений
- **5 FIX** - исправления критических багов
- **4 FEAT** - новые функции и возможности
- **5 STYLE** - улучшения UI/UX
- **3 REFACTOR** - рефакторинг кода
- **Итого**: 17 значимых изменений
