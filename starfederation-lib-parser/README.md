# Star Federation — универсальный парсер справочника

Tampermonkey-скрипт для [Звёздной Федерации](https://starfederation.ru/): эвристически собирает заголовок, основной текст, категории (breadcrumbs / сайдбар), ссылки на похожие страницы, перехватывает JSON из `fetch`/`XMLHttpRequest` и при необходимости обходит несколько страниц того же сайта с задержкой.

**Работает только на `https://starfederation.ru/`** (и `https://www.starfederation.ru/`), на остальных сайтах не запускается.

## Установка

1. Установите [Tampermonkey](https://www.tampermonkey.net/) в браузер.
2. Создайте новый скрипт и вставьте содержимое файла [`starfederation-lib-parser.user.js`](./starfederation-lib-parser.user.js).
3. Сохраните скрипт и откройте любую страницу на [starfederation.ru](https://starfederation.ru/).

## Использование

- В правом верхнем углу появляется кнопка **«Собрать данные»**.
- По нажатию:
  - собираются данные текущей страницы;
  - результат выводится в консоль (`[SF][PAGE_DATA]`);
  - скачивается JSON-файл.
- Кнопка **«Авто 5–10»** в панели: рекурсивно обходит до 5–10 страниц того же origin с паузой между запросами, сохраняет один JSON с массивом `pages`.
- Кнопка **«Собрать справочник»**: раскрывает дерево `WndHelp`, затем **по каждой найденной статье** открывает её и сохраняет данные из `#WndHelp_content`. В `CFG` параметр **`maxWndHelpPages`**: `0` (по умолчанию) — **без лимита**, все статьи; положительное число — максимум страниц в одном прогоне.
- **«Стоп»** — останавливает обход (после текущего шага); в конце выгружается JSON с пометкой `stopped` / с суффиксом `stopped` в имени файла.
- **«Скачать сейчас»** — скачать уже собранные страницы без ожидания конца прогона.
- **«Сбросить прогресс»** — очистить сохранённые id (чтобы заново собрать всё с нуля); id дублируются в хранилище Tampermonkey для пропуска уже обработанных при повторном запуске.
- В `CFG` (опционально): **`wndHelpDownloadEvery`** — если `> 0`, то каждые N собранных страниц дополнительно скачивается `starfederation-wndhelp-part-XXX-....json`. По умолчанию **0** (авто-скачивание фрагментов отключено); прогресс по id по-прежнему в хранилище, плюс кнопки **«Скачать сейчас»** и итоговый файл в конце / по **«Стоп»**.

Ответы API в формате JSON логируются в консоль с префиксом `[SF][JSON]`; кандидаты в «похожие на API» эндпоинты дополнительно собираются в `[SF][API_ENDPOINTS?]` при сборе страницы.

### Блок контента справочника

Текст статьи и заголовки секций (`span.title`, списки и т.д.) читаются из DOM-элемента **`#WndHelp_content`** (классы вида `content_box textbox-g helpcontent`). Автосбор ждёт наполнения этого блока, а не ответа `JSONDATA` в сети.

### Особенность справочника StarFederation

Часть страниц справочника грузится через URL вида:

- `https://starfederation.ru/?m=windows&w=WndHelp&a=lc&id=Sciences-204&level=0&_mt=...`

В ответе может быть `text/html`, но с встроенным маркером `<!-- JSONDATA {...} -->`. Скрипт извлекает этот `JSONDATA` и логирует в консоль как `[SF][JSONDATA][fetch]` / `[SF][JSONDATA][xhr]`, а такие ссылки считает “похожими страницами” для автообхода.

## Формат JSON (одна страница)

```json
{
  "url": "...",
  "title": "...",
  "content": "...",
  "headings": [],
  "links": [],
  "category": "...",
  "raw_html": "..."
}
```

Поле `headings` — массив объектов `{ "level": "h1|h2|h3", "text": "..." }`.  
Поле `links` — массив `{ "url": "...", "text": "..." }` (отфильтрованные «похожие» внутренние ссылки).

## Формат JSON (автообход)

```json
{
  "crawled_at": "ISO-8601",
  "seed": "начальный URL",
  "pages": [ /* те же объекты, что выше */ ]
}
```

## Ограничения и замечания

- Разметка не фиксирована: выбор «основного блока» — эвристика по объёму текста и штрафам за навигацию/рекламу; на отдельных страницах может понадобиться ручная проверка.
- Рекурсивный обход использует `fetch` HTML; страницы, требующие только клиентского рендера без полного HTML в ответе, могут собираться неполно.
- Задержка между запросами и лимит страниц настраиваются в начале файла `CFG` (`crawlDelayMs`, `maxAutoPages`).
